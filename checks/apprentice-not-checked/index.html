What the rule says

Apprentices. A dated summary, not legal advice. Sources read 8 November 2026. Example checked 10 November 2026.

29 CFR 5.5(a)(4)(i) allows less than the predetermined rate only for apprentices who meet its registration conditions. The program supplies apprentice wage terms; the checker does not hold those program records.

Apprentice fringe follows the program. If the program does not specify fringe benefits, 29 CFR 5.5(a)(4)(i)(B) says the full wage determination fringe must be paid. The tool therefore does not use the journeyworker rate table as an apprentice pay test.

If the apprenticeship program does not specify fringe benefits, apprentices must be paid the full amount of fringe benefits listed on the wage determination

29 CFR 5.5(a)(4)(i)(B). Source read 8 November 2026.

A week that trips it

The worker names, trades and rates are made up and illustrative. Both result boxes below are printed from the free checker's output for the displayed CSV and rate table.

Fay H. is marked yes in the apprentice column. Ana R. is the journeyworker for the same trade on every workday. The entered ratio allows their daily count, so the first result contains only the apprentice-pay note. There is no claim that the apprentice's wage or fringe was verified.

This note is expected even when a contractor has already checked the program records. The export tells the tool a worker is an apprentice, but it does not supply a wage step, registration evidence or program benefit terms. Those missing facts cannot be inferred from the dollar amounts.

The fix

Review Fay's registration, wage step, fringe and overtime against the program outside the checker. An accurate apprentice row keeps this note after that review. There is no pay-rate entry that clears it while the row remains an apprentice.

The corrected comparison below represents a later week in which Fay actually works as a journeyworker. The row then records no for apprentice, a $30.00 wage and a $10.00 plan credit. Those add to $40.00 each hour. Both parts apply to every recorded hour. That different status enables the full-rate checks. Never change the status of a real apprentice just to remove the note.

What the checker doesn't check here

Registration, probation, program pay steps and graduated ratios are not checked. The ratio count is separate from the wage review, and it uses only the workers present in this one file.

The corrected example does not establish that an apprentice completed a program. Any real change in role needs its own work records. The checker accepts the status field as typed.

Questions about this check

Can an unregistered worker receive the apprentice rate?

No. Under 29 CFR 5.5(a)(4)(i), a worker paid an apprentice rate who is not registered must receive the full rate. The exception is a certified probationary apprentice in the first 90 days.

What if the program says nothing about fringe?

29 CFR 5.5(a)(4)(i)(B) says the apprentice must receive the full fringe amount on the wage determination when the program does not specify fringe benefits.

Does a ratio within the limit mean apprentice pay was checked?

No. The checker checks apprentice rows for the ratio only and leaves program pay and overtime unchecked.
